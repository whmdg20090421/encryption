========================================
Termux 本地编译环境搭建指南
========================================

前置条件：手机性能足够，存储空间 > 2GB

========================================
第一步：安装 Termux
========================================

从 F-Droid 下载 Termux（不要用 Play Store 版本，版本老旧）
https://f-droid.org/packages/com.termux/

========================================
第二步：安装基础依赖
========================================

pkg update && pkg upgrade
pkg install openjdk-21 git

========================================
第三步：安装 Android SDK
========================================

# 下载 Android commandline-tools
mkdir -p ~/android-sdk/cmdline-tools
cd ~/android-sdk/cmdline-tools
wget https://dl.google.com/android/repository/commandlinetools-linux-11076708_latest.zip
unzip commandlinetools-linux-11076708_latest.zip
mv cmdline-tools latest

# 设置环境变量
echo 'export ANDROID_HOME=$HOME/android-sdk' >> ~/.bashrc
echo 'export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools' >> ~/.bashrc
source ~/.bashrc

# 安装必要的 SDK 组件
yes | sdkmanager --licenses
sdkmanager "platforms;android-36" "build-tools;36.0.0" "platform-tools"

========================================
第四步：克隆项目
========================================

cd ~
git clone <你的项目仓库地址>
cd Android_tools

========================================
第五步：创建 preview 项目（后续由 Claude Code 完成）
========================================

# preview 项目结构：
# Android_tools_preview/
# ├── build.gradle.kts          (只依赖 Compose + Material3)
# ├── settings.gradle.kts
# ├── gradle.properties
# ├── gradle/wrapper/
# ├── app/
# │   ├── build.gradle.kts      (minSdk 24, compileSdk 36, 无 native)
# │   ├── src/main/
# │   │   ├── AndroidManifest.xml
# │   │   ├── java/com/preview/
# │   │   │   ├── MainActivity.kt    (壳子，直接调用目标 Composable)
# │   │   │   └── screens/           (从主项目复制的 .kt 文件)
# │   │   └── res/
# │   │       └── values/themes.xml

========================================
第六步：编译安装流程
========================================

# 每次预览的流程：
# 1. Claude Code 修改主项目的某个 .kt 文件
# 2. 运行同步脚本，把目标文件 + import 依赖复制到 preview 项目
# 3. 编译安装

cd ~/Android_tools_preview
./gradlew installDebug

# 如果连接了 USB 调试，会自动安装到手机
# 如果用 Termux 本地编译（同一台手机），安装后直接打开看效果

========================================
注意事项
========================================

- preview 项目不包含 native 代码（JNI/NDK），编译速度快
- preview 项目不包含加密模块、Shizuku、文件管理器等重量级依赖
- 每次预览只编译一个屏幕文件 + 它的 import 链
- 预计编译时间 1-3 分钟（取决于手机性能）
- 首次编译需要下载 Gradle 和依赖，会比较慢（约 5-10 分钟）
- 后续编译有缓存会快很多
