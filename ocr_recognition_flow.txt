OCR 账单识别完整流程

=== 1. 用户点击识别按钮 ===

触发位置：OcrFloatingWindow.kt - onBubbleClicked()
状态：BUBBLE → MENU（展开菜单）→ 用户点击"识别"按钮
调用：startRecognition(context, bubble, density)

=== 2. 截图阶段 ===

代码位置：MyAccessibilityService.kt - takeScreenshot()
API：AccessibilityService.takeScreenshot()（Android 11+）
前置条件：accessibility_service_config.xml 中 android:canTakeScreenshot="true"
返回：Bitmap（内存中，不保存到文件）
线程：在 IO 线程执行（withContext(Dispatchers.IO)）

=== 3. 截图动画阶段 ===

代码位置：OcrFloatingWindow.kt - showScreenshotAnimation()
流程：
1. 创建全屏透明窗口（TYPE_APPLICATION_OVERLAY）
2. 在窗口中添加 ImageView 显示截图
3. 动画效果：截图从屏幕中央（80%大小）缩小并移动到悬浮窗位置
4. 动画时长：500ms，使用 AccelerateInterpolator
5. 动画结束后：
   - 清除 ImageView 的 bitmap 引用（imageView.setImageDrawable(null)）
   - 移除动画窗口
   - 调用 onAnimationEnd 回调

保护机制：
- 如果动画被取消（onAnimationCancel），会立即回收 bitmap
- 动画结束后才开始 OCR 识别，避免 bitmap 被提前回收

=== 4. OCR 识别阶段 ===

代码位置：BillOcrEngine.kt - recognizeFromBitmap()
OCR 引擎：Google ML Kit 中文文字识别（text-recognition-chinese:16.0.1）
流程：
1. 获取前台应用包名（topPackage 或 getTopPackageFromWindow()）
2. 检查包名是否在支持列表中（支付宝/QQ/微信）
3. 使用 InputImage.fromBitmap(bitmap, 0) 创建输入图像
4. 调用 textRecognizer.process(image).await() 进行 OCR 识别
5. 获取识别出的文字（result.text）
线程：在 IO 线程执行

=== 5. 关键词匹配阶段 ===

代码位置：BillOcrEngine.kt - matchesBillKeywords()
关键词列表：
- 付款、收款、¥、￥、支付、转账、红包
- 账单、交易、消费、收入、到账、充值
- 零钱、余额、银行卡
逻辑：只要文字中包含任意一个关键词，就认为匹配成功

=== 6. 账单解析阶段 ===

代码位置：BillOcrEngine.kt - parseBill()
提取内容：
1. 金额提取（正则）：
   - ¥123.45 / ￥123.45
   - 123.45元
   - 支付/付款/收款/转账/消费 + 数字
2. 商户名提取（正则）：
   - 付款给 xxx
   - 向 xxx 付款
   - 商户：xxx
   - 收款方：xxx
3. 类型判断：
   - 包含"收款/到账/收入/转入" → 收入
   - 否则 → 支出

返回：OcrBillResult 对象（type, amount, merchant, time, sourceApp, rawText, confidence, matchedRule）

=== 7. 结果展示阶段 ===

代码位置：OcrFloatingWindow.kt - showResult()
成功时显示：
- "识别成功"（绿色）
- 类型 + 金额（¥格式）
- 商户名
- 来源应用

失败时显示：
- 具体错误原因（红色）
- 如果是"未匹配到账单关键词"或"未解析到金额信息"，会同时显示识别到的文字（前200字符）用于调试

=== 错误处理 ===

可能的错误：
1. "无障碍服务未运行" - MyAccessibilityService.instance 为 null
2. "截图失败" - takeScreenshot() 返回 null（Android 版本 < 11 或权限问题）
3. "未检测到前台应用" - topPackage 和 getTopPackageFromWindow() 都返回 null
4. "当前应用不支持：xxx" - 包名不在 supportedApps 列表中
5. "OCR识别失败：xxx" - ML Kit 识别异常
6. "未识别到文字" - OCR 识别结果为空
7. "未匹配到账单关键词" - 文字中没有关键词
8. "未解析到金额信息" - 有关键词但正则无法提取金额

=== 关键配置 ===

1. 无障碍服务配置（accessibility_service_config.xml）：
   - android:canTakeScreenshot="true"（必须）
   - android:canRetrieveWindowContent="true"
   - android:accessibilityFlags="flagDefault|flagRetrieveInteractiveWindows|flagReportViewIds"

2. 支持的应用（BillOcrConfig.supportedApps）：
   - com.eg.android.AlipayGphone（支付宝）
   - com.tencent.mobileqq（QQ）
   - com.tencent.mm（微信）

3. 依赖库：
   - com.google.mlkit:text-recognition-chinese:16.0.1（ML Kit 中文 OCR）
   - org.jetbrains.kotlinx:kotlinx-coroutines-play-services:1.8.1（协程支持）

=== 已知限制 ===

1. 微信有反无障碍机制，节点树遍历无法获取内容，必须使用截图+OCR
2. 截图 API 仅支持 Android 11+（API 30+）
3. OCR 识别可能不准确，取决于截图质量和文字清晰度
4. 金额正则可能无法匹配所有格式（如"¥ 123.45"有空格的情况）
