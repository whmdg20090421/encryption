一、基础信息
================================================================================

【接口域名】
  https://open-api.123pan.com

【协议要求】
  - HTTPS 协议
  - JSON 数据格式
  - UTF-8 编码
  - POST 请求设置 Content-Type: application/json

【公共请求头】（所有接口都需要）
  ┌─────────────────┬────────┬──────────────────────────────┐
  │ 请求头名称       │ 类型    │ 说明                         │
  ├─────────────────┼────────┼──────────────────────────────┤
  │ Authorization    │ string │ "Bearer " + access_token     │
  │                  │        │ 注意: Bearer后面有空格        │
  │ Platform         │ string │ 固定值: open_platform         │
  │ Content-Type     │ string │ application/json              │
  └─────────────────┴────────┴──────────────────────────────┘

【响应格式】（所有接口统一）
  {
    "code": 0,          // 0=成功，其他=失败
    "message": "ok",    // 成功时为"ok"，失败时为错误信息
    "data": { ... },    // 响应内容，失败时为null
    "x-traceID": "..."  // 请求追踪ID（报错时提供给技术支持）
  }

【常用错误码】
  ┌──────┬──────────────────┐
  │ code │ 描述             │
  ├──────┼──────────────────┤
  │ 0    │ 成功             │
  │ 401  │ access_token无效 │
  │ 429  │ 请求太频繁       │
  └──────┴──────────────────┘

【Token 说明】
  - access_token 有效期: 30天
  - 同一 client_id 下最多同时 3 个 token 在使用
  - 多次颁发会踢掉旧 token
  - 建议本地保存 token，过期前及时重新获取

【限流 QPS】（与文件同步相关）
  ┌─────────────────────────────┬──────┐
  │ API                         │ QPS  │
  ├─────────────────────────────┼──────┤
  │ api/v1/access_token         │ 10   │
  │ upload/v1/file/mkdir        │ 20   │
  │ api/v1/file/list            │ 10   │
  │ api/v2/file/list            │ 15   │
  │ api/v1/file/move            │ 20   │
  │ api/v1/file/delete          │ 10   │
  └─────────────────────────────┴──────┘

二、认证 — 获取 access_token
================================================================================

【接口】POST /api/v1/access_token

【请求头】
  Platform: open_platform
  （注意：此接口不需要 Authorization）

【请求体】
  {
    "clientID": "你的clientID",
    "clientSecret": "你的clientSecret"
  }

【响应体】
  {
    "code": 0,
    "data": {
      "accessToken": "xxx",
      "expiredAt": "2026-09-10T00:00:00Z"
    }
  }

【备注】
  - client_secret 请安全保存，不要放在前端代码中
  - 有访问频率限制，建议本地缓存 token

────────────────────────────────────────────────────────────────────────────────
3.1 创建目录
────────────────────────────────────────────────────────────────────────────────

【接口】POST /upload/v1/file/mkdir

【请求体】
  {
    "name": "目录名",        // 不能重名
    "parentID": 0            // 父目录ID，根目录填0
  }

【响应体】
  {
    "code": 0,
    "data": {
      "dirID": 12345         // 创建成功的目录ID
    }
  }

【备注】
  - 目录名不能重名（同级目录下）

────────────────────────────────────────────────────────────────────────────────
3.2 获取文件列表（推荐 V2）
────────────────────────────────────────────────────────────────────────────────

【接口】GET /api/v2/file/list

【查询参数】
  ┌──────────────┬────────┬────────┬──────────────────────────────┐
  │ 参数名       │ 类型    │ 必填   │ 说明                         │
  ├──────────────┼────────┼────────┼──────────────────────────────┤
  │ parentFileId │ number │ 是     │ 文件夹ID，根目录传0          │
  │ limit        │ number │ 是     │ 每页数量，最大100            │
  │ lastFileId   │ number │ 否     │ 翻页用，上一页返回的值       │
  │ searchData   │ string │ 否     │ 搜索关键字（全局搜索）       │
  └──────────────┴────────┴────────┴──────────────────────────────┘

【响应体】
  {
    "code": 0,
    "data": {
      "lastFileId": 123,     // -1=最后一页，其他=下一页起始ID
      "fileList": [
        {
          "fileId": 123,
          "filename": "test.whm",
          "type": 0,           // 0=文件, 1=文件夹
          "size": 1024000,     // 字节
          "etag": "md5hash",   // 文件的MD5值
          "status": 0,         // 审核状态, >100=驳回
          "parentFileId": 0,
          "category": 0,       // 0=未知 1=音频 2=视频 3=图片
          "trashed": 0         // 0=正常, 1=在回收站
        }
      ]
    }
  }

【重要提示】
  ⚠ 此接口返回结果包含回收站文件！需自行根据 trashed 字段过滤。
  ⚠ 搜索时 searchData 会无视 parentFileId，进行全局查找。

四、文件管理 — 上传（V2 推荐）
================================================================================

────────────────────────────────────────────────────────────────────────────────
4.1 上传流程总览
────────────────────────────────────────────────────────────────────────────────

【分片上传流程（大文件，最大10GB）】
  1. 创建文件 → 获取 preuploadID + sliceSize + servers
     （如果 reuse=true，秒传成功，流程结束）
  2. 按 sliceSize 切分文件，计算每个分片的 MD5
  3. 上传分片 → POST 到 servers 域名，Content-Type: multipart/form-data
  4. 上传完毕 → 轮询直到 completed=true

【单步上传流程（小文件，最大1GB）】
  1. 获取上传域名
  2. 计算文件 MD5，直接上传完整文件
  Content-Type: multipart/form-data

────────────────────────────────────────────────────────────────────────────────
4.2 创建文件（分片上传第一步）
────────────────────────────────────────────────────────────────────────────────

【接口】POST /upload/v2/file/create

【请求体】
  {
    "parentFileID": 0,          // 父目录ID，根目录填0
    "filename": "test.whm",    // 文件名（<256字符，不能含 ":\/:*?|><）
    "etag": "文件的md5值",      // 整个文件的MD5
    "size": 1048576,            // 文件大小（字节）
    "duplicate": 1,             // 可选: 1=保留两者, 2=覆盖原文件
    "containDir": false         // 可选: true时filename传路径+文件名
  }

【响应体】
  {
    "code": 0,
    "data": {
      "fileID": 0,              // 秒传时返回文件ID
      "preuploadID": "xxx",     // 预上传ID（非秒传时）
      "reuse": false,           // true=秒传成功
      "sliceSize": 4194304,     // 分片大小（字节）
      "servers": ["https://upload-xxx.123pan.com"]  // 上传域名
    }
  }

【备注】
  - 文件名不能全部是空格
  - 开发者单文件大小限制: 10GB
  - reuse=true 表示秒传，此时没有 preuploadID
  - servers 有多个时任选其一

────────────────────────────────────────────────────────────────────────────────
4.3 上传分片（分片上传第二步）
────────────────────────────────────────────────────────────────────────────────

【接口】POST {上传域名}/upload/v2/file/slice
  ⚠ 注意：域名用 servers 返回的上传域名，不是 open-api.123pan.com
  ⚠ Content-Type: multipart/form-data

【请求头】
  Authorization: Bearer {access_token}
  Platform: open_platform

【表单字段】
  ┌──────────────┬────────┬────────┬──────────────────────────┐
  │ 字段名       │ 类型    │ 必填   │ 说明                     │
  ├──────────────┼────────┼────────┼──────────────────────────┤
  │ preuploadID  │ string │ 是     │ 创建文件时返回的值       │
  │ sliceNo      │ number │ 是     │ 分片序号，从1开始        │
  │ sliceMD5     │ string │ 是     │ 当前分片的MD5            │
  │ slice        │ file   │ 是     │ 分片二进制流             │
  └──────────────┴────────┴────────┴──────────────────────────┘

【响应】无返回数据

────────────────────────────────────────────────────────────────────────────────
4.4 上传完毕（分片上传第三步）
────────────────────────────────────────────────────────────────────────────────

【接口】POST /upload/v2/file/upload_complete

【请求体】
  {
    "preuploadID": "xxx"
  }

【响应体】
  {
    "code": 0,
    "data": {
      "completed": true,     // true=上传完成
      "fileID": 12345        // 文件ID
    }
  }

【备注】
  - completed=false 时，间隔1秒后再次轮询此接口

────────────────────────────────────────────────────────────────────────────────
4.5 获取上传域名（单步上传用）
────────────────────────────────────────────────────────────────────────────────

【接口】GET /upload/v2/file/domain

【响应体】
  {
    "code": 0,
    "data": ["https://upload-xxx.123pan.com"]  // 多个域名任选其一
  }

────────────────────────────────────────────────────────────────────────────────
4.6 单步上传（小文件，最大1GB）
────────────────────────────────────────────────────────────────────────────────

【接口】POST {上传域名}/upload/v2/file/single/create
  ⚠ 域名用 /upload/v2/file/domain 获取的域名
  ⚠ Content-Type: multipart/form-data

【请求头】
  Authorization: Bearer {access_token}
  Platform: open_platform

【表单字段】
  ┌──────────────┬────────┬────────┬──────────────────────────────────────┐
  │ 字段名       │ 类型    │ 必填   │ 说明                                 │
  ├──────────────┼────────┼────────┼──────────────────────────────────────┤
  │ parentFileID │ number │ 是     │ 父目录ID，根目录填0                  │
  │ filename     │ string │ 是     │ 文件名                               │
  │ etag         │ string │ 是     │ 文件MD5                              │
  │ size         │ number │ 是     │ 文件大小（字节）                     │
  │ file         │ file   │ 是     │ 文件二进制流                         │
  │ duplicate    │ number │ 否     │ 1=保留两者, 2=覆盖                   │
  │ containDir   │ bool   │ 否     │ true时filename传路径+文件名          │
  └──────────────┴────────┴────────┴──────────────────────────────────────┘

【响应体】
  {
    "code": 0,
    "data": {
      "fileID": 12345,
      "completed": true       // true=上传完成
    }
  }

【备注】
  - 文件名限制: <256字符，不能含 ":\/:*?|><
  - 单文件大小限制: 1GB
  - 秒传时也会返回 fileID

────────────────────────────────────────────────────────────────────────────────
4.7 SHA1 秒传上传（快速上传已知文件）
────────────────────────────────────────────────────────────────────────────────

【接口】POST /upload/v2/file/sha1_reuse

【请求体】
  {
    "parentFileID": 0,
    "filename": "test.whm",
    "sha1": "文件的SHA1值",
    "size": 1048576,
    "duplicate": 1            // 可选: 1=保留两者, 2=覆盖
  }

【响应体】
  {
    "code": 0,
    "data": {
      "fileID": 12345,        // 秒传成功时返回
      "reuse": true            // true=秒传成功
    }
  }

【备注】
  - 如果123云盘已有相同SHA1的文件，直接秒传（不消耗上传流量）
  - reuse=false 时需要走正常上传流程
  - 文件名限制同上

十、同步场景快速参考
================================================================================

【场景：上传本地文件到云端】
  小文件(≤1GB):
    1. GET /upload/v2/file/domain → 获取上传域名
    2. 计算文件MD5
    3. POST {域名}/upload/v2/file/single/create (multipart/form-data)

  大文件(≤10GB):
    1. 计算文件MD5
    2. POST /upload/v2/file/create → preuploadID + sliceSize + servers
    3. 按sliceSize切片，计算每片MD5
    4. 循环: POST {servers}/upload/v2/file/slice (multipart/form-data)
    5. POST /upload/v2/file/upload_complete → 轮询completed

  秒传（SHA1快速上传）:
    1. 计算文件SHA1
    2. POST /upload/v2/file/sha1_reuse
    3. reuse=true → 完成，reuse=false → 走正常上传流程

【场景：从云端下载文件】
  1. GET /api/v1/file/download_info?fileId=xxx → downloadUrl
  2. HTTP GET downloadUrl 下载文件

【场景：检查云端是否有某文件（SHA1/MD5比对）】
  方法1: SHA1秒传
    POST /upload/v2/file/sha1_reuse → reuse=true表示云端已有此文件
  方法2: 文件列表遍历
    GET /api/v2/file/list → 比对etag(MD5)字段
  方法3: 文件详情查询
    GET /api/v1/file/detail?fileID=xxx → etag字段为MD5

【场景：删除云端文件】
  POST /api/v1/file/trash → fileIDs数组（最多100个）

【场景：重命名云端文件】
  单个: PUT /api/v1/file/name
  批量: POST /api/v1/file/rename（最多30个）

【场景：移动云端文件】
  POST /api/v1/file/move → fileIDs + toParentFileID（最多100个）

【场景：创建目录】
  POST /upload/v1/file/mkdir → name + parentID → dirID

【场景：列出目录内容】
  GET /api/v2/file/list?parentFileId=xxx&limit=100
  翻页: lastFileId=上一页返回的lastFileId值
  ⚠ 记得过滤 trashed=0 的文件（排除回收站）

十一、文件名限制
================================================================================

  - 长度: < 256 个字符
  - 禁止字符: " / \ : * ? | > <
  - 不能全部是空格
  - 同级目录下不能重名（上传时可用 duplicate 参数控制覆盖策略）

================================================================================
十二、与项目集成的技术要点
================================================================================

【认证】
  - 使用 OkHttp 发送 POST 请求到 /api/v1/access_token
  - 本地缓存 token，过期前刷新
  - 请求头: Authorization: Bearer {token}, Platform: open_platform

【上传（推荐单步上传 ≤1GB）】
  - 计算文件MD5 (MessageDigest)
  - multipart/form-data 上传
  - 服务器域名从 /upload/v2/file/domain 获取
  - 秒传检查: SHA1接口优先

【下载】
  - 获取 downloadUrl 后直接 HTTP GET
  - 注意流量限制（每日1GB自用）

【文件比对】
  - 文件列表返回的 etag 字段 = 文件MD5
  - 可用于判断本地文件与云端是否一致
  - SHA1接口可用于秒传判断

【错误处理】
  - code=0 成功，其他失败
  - 401: token过期，需重新获取
  - 429: 限流，需降低请求频率
  - x-traceID: 报错时记录，便于排查
